Trusted agent graphs

Visual agent canvases are everywhere, and long agent runs are everywhere. Separately they fail you: the canvas still needs a human builder, and the long run is a black box you can’t safely promote.

The bet

Lock the architecture first, let Claude build the graph, run it to the goal in a sandbox, then you only review and promote.

The loop

  1. Grill features · tools · perms · tests →
  2. Claude builds the graph →
  3. Sandbox iterate to the goal →
  4. You review →
  5. Promote to prod

What the graph is

  • Inspectable flow of CLI / script nodes
  • Permissions set per node by the user
  • Browser, cloud, and apps as nodes that run that CLI
  • Every change must pass tests before it’s trusted
  • A good graph becomes a reusable nested module

First proof

A marketing-email drafting workflow, rebuilt as a graph and packaged as a Claude Cowork plugin. A ticket goes in and an unpublished CMS draft comes out.

  1. Ticket source copy →
  2. Gate no real copy, no draft →
  3. Claude drafts the HTML →
  4. You review the preview →
  5. Check HTML →
  6. You approve the upload →
  7. CMS draft, unpublished
  • 23 nodes and 28 edges, each one inspectable
  • 4 pauses: one hands the copy to Claude, three wait for a human
  • The run stops if the ticket has no real copy, so nothing gets made up
  • A Claude skill drives the run through the graph’s own API: start, watch, resume
  • A 9-step live test passed, and a direct CMS check confirmed the draft stayed unpublished

What this proves: a graph you can inspect, with gates, that can be reused as a plugin. What it doesn’t prove yet: Claude didn’t write this graph from a grilled spec, and the run still stops for a human partway through, so there’s no unattended sandbox loop. The retry after a failed HTML check doesn’t go anywhere yet either. Those are next.

What it is not yet

A chat UI that drives this — later. Economics — when we have real numbers.

The edge

Not another drag-and-drop canvas. The edge is pre-decided architecture, an AI-authored graph, a sandbox until it’s done, and one human gate to prod.

Living note. It started as a blueprint, and the first proof is now up. I’ll update it as the loop gets sharper.
