Trusted agent graphs

Visual agent canvases are everywhere, and long agent runs are everywhere. Separately they fail you: the canvas still needs a human builder, and the long run is a black box you can’t safely promote.

The bet

Lock the architecture first, let Claude build the graph, run it to the goal in a sandbox, then you only review and promote.

The loop

  1. Grill features · tools · perms · tests →
  2. Claude builds the graph →
  3. Sandbox iterate to the goal →
  4. You review →
  5. Promote to prod

What the graph is

  • Inspectable flow of CLI / script nodes
  • Permissions set per node by the user
  • Browser, cloud, and apps as nodes that run that CLI
  • Every change must pass tests before it’s trusted
  • A good graph becomes a reusable nested module

What it is not yet

A chat UI that drives this — later. Economics — when we have real numbers.

The edge

Not another drag-and-drop canvas. The edge is pre-decided architecture, an AI-authored graph, a sandbox until it’s done, and one human gate to prod.

Living note — early blueprint. I’ll update this as the loop gets sharper.
